Calculadora de Salario Neto

Aplicación desarrollada con Kotlin y Jetpack Compose. 

Permite calcular el salario neto a partir del bruto anual y diferentes datos personales.

Funcionalidades
- Introducción de datos personales y laborales.
- Cálculo del IRPF (15%).
- Cálculo de cotización a la Seguridad Social (6,5%).
- Cálculo de deducciones y salario neto.
- Interfaz desarrollada con Jetpack Compose.

Tecnologías
- Kotlin
- Android Studio
- Jetpack Compose
- Material 3

Ejecución

1.Clonar este repositorio.

2.Abrir el proyecto en Android Studio.

3.Sincronizar Gradle.

4.Ejecutar la aplicación en un emulador.
